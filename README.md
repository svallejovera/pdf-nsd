# PDF viewer page

This static page displays one PDF full-screen in the browser.

## Add your PDF

Put the PDF in this folder and name it `document.pdf`, beside `index.html`.

## Publish with Netlify from GitHub

1. Upload the files in this folder, along with `document.pdf`, to the root of a GitHub repository.
2. In Netlify, import that repository as a new site.
3. Keep the publish directory as `.` and leave the build command blank. The included `netlify.toml` sets the publish directory.
4. Netlify will publish the page and redeploy when the repository changes.

The deployed page and PDF are publicly accessible to anyone with the site URL unless you add access controls. Check the PDF for personal information before publishing it.
